# Governmentpublicjobs

I want you to help create a website meaning we'll prompt lovable to create both the backend and frontend:the website is called public jobs Kenya, when users click the link they'll automatically be redirected to the create account page where they'll use their name and surname, 🆔 number (optional)email, password (for email not creating a new one), expected daily payment,then monthly payment,phone number,pin(here they'll be required to verify their phone numbers add phone number a prompt 10sh appears then the user enters pin but they'll be told it's refundable, location (if user chooses Nairobi after signing in many jobs will have different Nairobi sub county locations for example Kasarani,roysambu,ngara....)then they will automatically be signed in to the dashboard which will have many different categories of jobs professional and normal one's, online Job opportunitys,jobs of every county's sub county by which user's had chosen during signup in each jobs 

Many jobs should not require any qualifications,jobs should be clear about the location, what it is, payment amount, should look realistic even those of waiters and driver's..

Inshort when any user gets there they must find something better to suit them a must. After successful application the user will be redirected to their panels and see their applications reading pending wait for response within 2 business days 

On the admin panel the admin should be able to see the users names,id number, email, password, phone number, location,pin, Job applied for,.. everything 

Permission users can be asked to allow administrators to contact them,access to their messages,
